# Ⅰ 表記の原則

「現代仮名遣い」による漢字平仮名交じり文を基本とし、特別な場合を除いて左横書きにする。

## 目次

1. 漢字の使い方
2. 送り仮名の付け方（公用文で送り仮名を省く186語）
3. 外来語の表記
4. 数字の使い方
5. 符号の使い方
6. その他の原則

## 1 漢字の使い方

基準は「常用漢字表」（平成22年内閣告示第2号）と「公用文における漢字使用等について」（平成22年内閣訓令第1号）。解説・広報等では、漢字で書く語でも仮名で書いたり振り仮名を付けたりしてよい。

### 1-1 常用漢字表の字種・音訓で書けない語

| 方法 | 例 |
|---|---|
| 訓による語は平仮名で書く | 敢えて→あえて、予め→あらかじめ、或いは→あるいは、概ね→おおむね、叶う→かなう、則る→のっとる、捗る→はかどる、以て→もって、依る・拠る→よる、宜しく→よろしく |
| 音による語でも漢字なしで通じるものは平仮名 | 斡旋→あっせん、杜撰→ずさん、石鹼→せっけん、咄嗟→とっさ、煉瓦→れんが |
| 動植物名は表にない字なら仮名、表にあれば漢字（学術名は片仮名が多い） | 鼠→ねずみ（ネズミ）、駱駝→らくだ、犬（イヌ）、桜（サクラ） |
| 同じ訓を持つ常用漢字で書く | 活かす→生かす、伐る・剪る→切る、解る・判る→分かる、拓く→開く、手許→手元、想い→思い、哀しい→悲しい |
| 同じ音で意味の通じる常用漢字で書く | 恰好→格好、義捐金→義援金、醵出金→拠出金、車輛→車両、穿鑿→詮索、洗滌→洗浄、顚覆→転覆、日蝕→日食、編輯→編集、抛棄→放棄、聯合→連合 |
| 常用漢字を使った別の語に言い換える | 隘路→支障・困難、軋轢→摩擦、竣工→落成・完工、捺印→押印、逼迫→切迫、罹災→被災、論駁→反論 |
| 同じ意味の分かりやすい言い方にする | 安堵する→安心する、陥穽→落とし穴、狭隘な→狭い、誤謬→誤り、塵埃→ほこり、脆弱な→弱い・もろい、凌駕する→しのぐ・上回る、漏洩する→漏らす、帰趨→動向、斟酌→遠慮 |
| 言い換えられないときは表外字だけ仮名にするか振り仮名を付ける | 改竄→改ざん（改竄に振り仮名）、牽引→けん引、招聘→招へい、綴る→つづる |
| 化学用語などは片仮名もある | 燐酸→リン酸、沃素→ヨウ素、弗素→フッ素 |

振り仮名の付け方
- 原則として、熟語のうち表にない漢字・音訓だけに付ける（読み手に配慮して熟語全体に付けてもよい）。
- 出るたびに付けなくてよい。文書全体か章ごとの初出など、基準を決めて統一する。見出しではなく本文に付けるのが一般的。
- 振り仮名が使えない環境では括弧で示す。熟語は全体の読みを示す。例：忸怩（じくじ）たる思い、招聘（しょうへい）する。

### 1-2 常用漢字表にあっても仮名で書く語

| 品詞・用法 | 仮名で書く例 | 漢字で書く場合 |
|---|---|---|
| 助詞 | くらい（程度）、など（例示）、ほど（程度） | 「等」は「とう」と読むときに使う |
| 助動詞 | ～のようだ、（やむを得）ない | |
| 補助的な用法の動詞・形容詞 | ～ていく、～ていただく、～てくださる、～てくる、～てみる、～てほしい、～てよい | 実際の動作・状態なら漢字：街へ行く、賞状を頂く、東から来る、資格が欲しい |
| 形式名詞 | こと、とき、ところ、もの、うち、ため、とおり、ゆえ、よう、わけ | 具体的な対象があるなら漢字：事は重大である、法律の定める年齢に達した時、家を建てる所、裁判所の指名した者、大通り、訳あって |
| 指示代名詞 | これ、それ、どれ、ここ、そこ、どこ | |
| 実質的な意味が薄れた語 | ありがとう、おはよう、こんにちは、逆さま | 「有り難い」は漢字 |
| 当て字・熟字訓（付表にないもの） | いつ、いかん、思わく、さすが、すばらしい、たばこ、ちょっと、ふだん、めった | 付表にない熟字訓（明後日、十八番）は音読みでだけ使い、訓読みなら仮名か振り仮名 |
| その他 | ～するとともに | 「彼と共に」は漢字 |

仮名書きを基本とし、一部を漢字で書くもの
- 接続詞：さらに、しかし、しかしながら、したがって、そして、そこで、それゆえ、ただし、ところが、ところで、また。ただし副詞の「更に」「更なる」「又」、動詞「従う」は漢字。
- 漢字で書く接続詞：**及び、又は、並びに、若しくは**。
- 連体詞：あらゆる、ある（～日）、いかなる、いわゆる、この、その、どの。漢字で書く連体詞：来る（きたる）、去る、当の、我が。
- 接頭辞・接尾辞：お菓子、お願い、～げ、～とも（二人とも）、～たち、～ら、～ぶる、～ぶり、～み。「御（おん・ご）」は漢字（御中、御礼、御挨拶、御意見）。ただし表外字を含む語は「御」も仮名（ごちそう、ごもっとも）。

動詞・副詞・形容詞は漢字が基本だが、一部は仮名
- 動詞：いる、できる（「出来が良い」は漢字）、なる（「本表と付表から成る」は漢字）。
- 副詞：いろいろ、おおむね、おのずから、いかに、いずれ、かなり、ここに、たくさん、ちょうど、とても、やがて、よほど、わざと、わざわざ。
- ある・ない：「問題がある」「欠点がない」は仮名。有無の対照や所在・存在を強調するときは漢字（財産が有る、有り・無し、在り方、アジアの東に在る）。

法令に倣って仮名で書く：おそれ（虞）、かつ（且つ）、ただし（但し）、ただし書、ほか（外・他）、よる（因る）。

解説・広報等では、本来漢字で書く次の語を仮名にしてもよい：ご指導・ご参加（御）、および・または・ならびに・もしくは、あくまで、あまり、いくら、すでに、ただちに、なにぶん、まさに。

## 2 送り仮名の付け方

- 「送り仮名の付け方」（昭和48年内閣告示第2号）の本則・例外に従う（学校教育と同じ）。
- 公用文（特に告示・通知等）では、読み間違えるおそれのない活用のない複合語（名詞）186語は「許容」を適用して送り仮名を省く。
- 同じ漢字の複合語でも動詞は本則どおり送る：入れ替える、売り上げる、仕分ける、問い合わせる、申し合わせる、呼び出す。
- 解説・広報等では、学校教育の表記（送り仮名を省かない）を使ってよい：食品売り場、期限付きの職、解約の手続き、雇い主責任。
- 慣用が固定した名詞（取締役、書留、子守、献立、日付 等）は送り仮名を付けない（通則7）。判断できないときや読みにくいときは省かずに書いてもよい。

## 3 外来語の表記

- 「外来語の表記」（平成3年内閣告示第2号）による。第1表（広く使われている表記）を基本とし、必要に応じて第2表（原音に近い表記）を使う。両表にない表記は使わない。
- 定着した語は広く使われる表記で：セロハン、プラスチック、デジタル（セロファン、プラスティック、ディジタルとはしない）。
- 原語との関連付けが慣用になっている語や固有名詞は第2表も使う：ウェイト、ウェブ、クォーク、フュージョン、ウィリアム、ウェールズ。
- 一般の用語は第1表が基本（ウイルス、ウエディング、ウオーター）。第2表を使う場合は文書内で統一する。
- 「ヴ」はむやみに使わず「バビブベボ」を使う。
- 長音は長音符号で書く：エネルギー、グループ、メール。慣用で符号を使わない語：バレエ（舞踊）、ミイラ、エイト、ペイント、レイアウト、サラダボウル。
- 語末の -er、-or、-ar や -ty、-ry も長音符号を付ける：コンピューター、エレベーター、カレンダー、コミュニティー、カテゴリー。

## 4 数字の使い方

- 横書きでは算用数字：令和2年11月26日、午後2時37分、72％。
- 大きな数は3桁ごとにコンマ：5,000、62,250円、1,254,372人。
- 兆・億・万は漢字：5兆、100億、30万円。万以上の単位を併用する場合はコンマを省いてもよい（1億2644万3000人）。
- 全角・半角の使い分けは文書内で統一する。データや金額などの数値は半角（全角は数値として扱われないことがある）。
- 概数は漢数字：二十余人、数十人、四、五十人。算用数字で統一したいときは「20人余り」「40～50人」と工夫する。
- 語を構成する数は漢数字：二者択一、三日坊主、再三再四、三権分立、六法全書、七福神、七五三、四十九日。
- 常用漢字表の訓による数え方は漢数字：一つ、二つ、一人（ひとり）、二日（ふつか）。広報等で明確に数を数える場合に限り「1つ、2つ」もある。
- 縦書きでは漢数字。縦書きの漢数字を横書きで引用するときは原則として算用数字に直す。
- 横書きの算用数字では「3か所」「7か月」。「3ヶ所」「7カ月」とはしない。漢数字では「三箇所」「七箇月」「数箇所」「何箇月」。

範囲を表す語
- 起点を含む：以上、以下、以前、以後（100人以上＝100人を含む）。
- 起点を含まない：超える、未満、満たない、前、後（100人を超える＝100人を含まない）。
- 「昭和期以前」のように幅のある語は誤解されやすいので「大正時代が終わるまで」などと言い換える。
- 期間：満5年・5か年・5年ぶり・5周年はまるまる5年。5年目・5年越し・5年来は起算の年を含んで5年。

## 5 符号の使い方

句読点・括弧
- 句点「。」、読点「、」が原則。横書きでは読点に「，」も可。文書内で統一し、混在させない。句点に「．」は使わない（学術的に必要な場合などを除く）。
- 「・」は並列する語、外来語や人名の区切り、箇条書の冒頭に使う：赤・緑・青、ケース・バイ・ケース、マルコ・ポーロ。
- 括弧は（）と「」が基本。入れ子でも同じ括弧を重ねる：（平成26（2014）年）、「「異字同訓」の漢字の使い分け例」。解説・広報等では「」の中に『』も可。
- 括弧の中で文が終わるときは閉じ括弧の前に「。」：（以下「基本計画」という。）、「決める。」と発言した。
- 引用部分や文でないもの（名詞、強調、日付等）、名詞で終わる場合は打たない：「決める」という動詞、国立科学博物館（上野）。
- 文末の括弧が部分的な注釈なら閉じ括弧の後に「。」。二つ以上の文や文章全体の注釈なら、最後の文の「。」の後に括弧を置く。
  - 例：年内にも再開を予定している（日程は未定である。）。
  - 例：年内にも再開を予定している。（別紙として、経緯に関する資料を付した。）
  - 解説・広報等では、文が終わっていることが明らかなら括弧内の句点を省いてよい：再開を予定しています（日程は未定です）。
- 【】は項目や強調に使う：【会場】文部科学省講堂、【取扱注意】。そのほかの括弧はむやみに使わず、使うなら用法を統一。

その他の符号
- 「？」「！」は解説・広報等や発言の記録で必要に応じて使ってよい。後に文が続くときは1字空ける。
- 「：」「―」「‐」「～」「…」「＊」「※」「／」などは慣用に倣い、文書内で用法を統一し、多用しない。文字化けしやすい符号に注意する。
  - ：項目と内容の区切り（住所：東京都千代田区…）
  - ‐（ハイフン）：番号の区切り（03‐5253‐****）
  - ～：起点と終点（10時～12時、東京～京都）
  - …：続くものの存在（牛、馬、豚、鶏…）
- 矢印（→、⇒）や箇条書の記号（・、○、●、◆、■ 等）、単位記号（℃、％、￥）も文書内で統一する。

## 6 その他の原則

- 文の書き出しや改行後は原則として1字下げる。ウェブやメール・SNSでは段落間を空けるなどの工夫でもよい。
- 繰り返し符号は「々」のみ：並々ならぬ、国々、正々堂々。複合語の切れ目では使わない：民主主義、○○党党首。2字以上の繰り返しはそのまま書く：ますます、一人一人、一歩一歩。
- 項目の階層の例
  - 横書き：第1 → 1 → （1） → ア → （ア）
  - 縦書き：第一 → 一 → 1 → （一） → （1） → ア
- ローマ字の全角・半角は文書内で統一。欧文は半角。
- 日本人の姓名のローマ字表記は「姓―名」の順。姓と名を区別させる必要があれば姓を全て大文字にする：YAMADA Haruo。
- 機種依存文字（丸囲み数字、半角カナ等）は文字化けに注意する。
- 読みやすいフォントを選ぶ（書体・色・大きさ）。
- 略語は初出で元の語を示す：知的財産（以下「知財」という。）、クオリティー・オブ・ライフ（Quality of Life。以下「ＱＯＬ」という。）。一般向けの文書で略語だけを使わない。
- 図表には分かりやすい位置に標題を付ける。軸名や凡例を示し、色覚の多様性と白黒印刷に配慮する。
