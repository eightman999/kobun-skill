# 公用文作成の考え方

文化審議会建議「公用文作成の考え方」（令和4年1月7日）とその解説を、文章作成・校正の手順に整理したもの。政府の公式な資料ではない。判断に迷う点は原典を確かめる。

## 手順

1. **文書の種類と読み手を決める。** 下の表から一つ選ぶ。依頼から読み取れなければ「記録・公開資料等」を既定とし、その前提を回答に書く。
2. **種類に応じて表記の厳しさを選ぶ。**
   - 告示・通知等：公用文表記の原則どおりに書く（法令と表記を一致させる）。
   - 記録・公開資料等：原則に基づき、必要に応じて読み手に合わせて工夫する。
   - 解説・広報等：読みやすさを優先し、仮名書き・送り仮名の付加・言い換え・「？」「！」も許される。ただし公用文としての品位は保つ。
3. **書く・直す。** 表記は [references/hyoki.md](references/hyoki.md)、用語は [references/yogo.md](references/yogo.md)、文体・文・構成は [references/bunsho.md](references/bunsho.md) を必要な箇所だけ読む。
4. **点検する。** 下のチェックリストを通す。校正の依頼では、修正後の文と主な修正点（理由を短く）を示す。
5. **事実は補わない。** 日付・期限・数量など、具体化に必要な情報が元の文にないときは「○月○日」のような空欄にし、書き手に確認するよう伝える。

## 公用文の分類

| 大別 | 具体例 | 想定される読み手 |
|---|---|---|
| 法令 | 法律、政令、省令、規則 | 専門的な知識がある人 |
| 告示・通知等 | 告示・訓令、通達・通知、公告・公示 | 専門的な知識がある人 |
| 記録・公開資料等 | 議事録・会見録、統計資料、報道発表資料、白書 | ある程度の専門的な知識がある人 |
| 解説・広報等 | 法令・政策の解説、広報、案内、Q&A、質問への回答 | 専門的な知識を特に持たない人 |

法令そのものの起草は対象外（法制執務の規則に従う）。

## 基本姿勢

- 読み手とのコミュニケーションとして書く。広く一般向けなら義務教育の範囲の知識で分かるように。
- **正確に**（誤りがない、元の情報の意味を損なわない、厳密さを求めすぎない）、**分かりやすく**（伝えることを絞る、主旨を先に、専門用語・外来語をむやみに使わない）、**気持ちに配慮して**（対外的には「です・ます」で簡潔に敬意を示し、型にはまった表現を避ける）。

## チェックリスト

表記
- [ ] 常用漢字表にない漢字・音訓を使っていない（使う場合は振り仮名か言い換え）。
- [ ] 助詞・助動詞・補助用言・形式名詞・接続詞は仮名（こと、とき、ところ、もの、ため、ていく、ください、さらに、ただし）。ただし「及び・又は・並びに・若しくは」は漢字（解説・広報等では仮名も可）。
- [ ] 送り仮名：告示・通知等と記録・公開資料等では、複合名詞186語の送り仮名を省く（手続、取扱い、申込み、打合せ 等）。解説・広報等では学校教育の表記（手続き、取り扱い）にしてよい。どちらにするかは文書内で統一する。動詞は常に本則（取り扱う、申し込む）。
- [ ] 横書きは算用数字。3桁区切りのコンマ、兆・億・万は漢字、概数と熟語は漢数字。「3か所」「7か月」（「ヶ」「カ」は使わない）。
- [ ] 句読点は「。」「、」（横書きで「，」も可。文書内で統一）。括弧内で文が終われば「。」を打つ。
- [ ] 全角・半角、符号、箇条書の記号を文書内で統一。繰り返し符号は「々」のみ。
- [ ] 略語は初出で正式名称を示す（「知的財産（以下「知財」という。）」）。

用語
- [ ] 難しい漢語・専門用語・外来語は、言い換えるか説明を付ける。
- [ ] 「から」と「より」を使い分ける（起点は「から」、比較は「より」）。
- [ ] 「早めに」「幾つか」「等」などの曖昧な語を具体化する。
- [ ] 重複表現・回りくどい表現を削る（「することができる」→「できる」）。
- [ ] 偏見や差別につながる表現、読み手を不快にする表現がない。

文・文書
- [ ] 常体と敬体を混ぜない。告示等は常体、特定の相手への通知・依頼・回答は敬体。
- [ ] 一文は短く、論点は一つ。三つ以上の並列は箇条書。
- [ ] 主語と述語が対応し、修飾語と被修飾語が近い。二重否定・受身を多用しない。
- [ ] 結論を先に示す。標題で主題と文書の性格（報告、依頼、開催 等）が分かる。
